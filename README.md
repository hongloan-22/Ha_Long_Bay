# Bài thực hành HTML: Vịnh Hạ Long

## Nội dung
Trang HTML giới thiệu Vịnh Hạ Long, sử dụng các thẻ cơ bản:
- `<h1>`: tiêu đề chính.
- `<p>`: các đoạn văn bản.
- `<img>`: hiển thị hình ảnh với các thuộc tính `src`, `alt` và `width`.
- `<a>`: liên kết đến trang Wikipedia về Vịnh Hạ Long.

## Cách mở
Nhấp đúp vào `halong_bay.html` để mở bằng trình duyệt web. Cần kết nối Internet để tải hình ảnh từ Unsplash.
